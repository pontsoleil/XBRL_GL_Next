# TaxonomyFramework（日本語案内）

このディレクトリには、XBRL GL NextのRequirements Specification、Taxonomy Framework文書、および登録済みサンプル成果物のinventoryが格納されています。

正式なFramework文書は英語で管理します。この`README_ja.md`は、TaxonomyFrameworkディレクトリにどの文書があるかを日本語で案内するためのものであり、Framework文書そのものの日本語訳ではありません。

## Inventory

[INVENTORY.md](INVENTORY.md)には、セマンティックモデルの成果物、正式な実行tools、tests、生成済みtaxonomy、サンプルinstance、検証結果、SHA-256を記録しています。

inventoryの日本語訳を[INVENTORY_ja.md](INVENTORY_ja.md)として提供します。
