# TaxonomyFramework

This directory contains the 6 November 2026 XBRL GL Next Taxonomy Framework Requirements Specification and Parts 1–5, provided in DOCX and PDF formats for public collaborative review.

These documents are collaborative review drafts. Their publication does not imply endorsement or approval as a standard by XBRL International, XBRL Japan or another organisation. The Requirements filename uses the plural `Requirements_Specification`; the document title is Requirements Specification.
