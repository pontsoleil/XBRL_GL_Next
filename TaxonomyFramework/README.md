# TaxonomyFramework

This directory contains the XBRL GL Next Requirements Specification, Taxonomy Framework documents, and the inventory of the registered sample artifacts.

The formal Framework documents are maintained in English. `README_ja.md` provides a Japanese guide to the contents of this directory; it is not a Japanese translation of the Framework documents themselves.

## Inventory

[INVENTORY.md](INVENTORY.md) records the semantic-model artifacts, canonical execution tools, tests, generated taxonomy, sample instances, validation results, and SHA-256 values.

A Japanese translation of the inventory is provided as [INVENTORY_ja.md](INVENTORY_ja.md).
