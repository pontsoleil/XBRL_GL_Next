# 統合契約

このディレクトリには、XBRL GL Nextと利用側プロジェクトとの境界で使用する、
プロジェクト作成のドラフト契約を格納します。

## この候補に登録済み

- `consumer-mapping-template.csv`は、内容を持たないスキーマ専用テンプレートです。
  移行時には、利用側profileごとに別のコピーへ記入します。
- テンプレートには、実取引、個人情報、認証情報、機密設定又はローカル絶対パスを
  記録してはなりません。
- `source_file_sha256`、契約名／版、review状態、reviewer role及びreview時刻により、
  個人名を必須にせず移行来歴を保持します。

## 計画中・未登録

- `release-manifest.schema.json`は計画中であり、この登録候補には含まれません。
- version付きprovider release package及びその機械可読manifestも計画中です。
  登録・検証されるまで、利用可能な成果物として記載してはなりません。

これらの契約はversion管理します。任意列の追加は後方互換としますが、列の意味の
変更又は必須列の削除は後方互換ではありません。

リポジトリのライセンスは、プロジェクトが作成した契約文及びテンプレートだけに
適用します。第三者の原資料、派生taxonomy、利用側データ又は外部標準を再ライセンス
するものではありません。権利が未解決の資料は、Private repositoryにも登録しません。
