# Tavi 静的HTML Viewer

Tavi関連データを表示する静的HTMLのデモを公開しています。公開済みページは直接閲覧できます。現行の公開ツールには、ローカルHTML Viewer生成プログラムは含まれません。

- [Simple Tavi Viewer](https://pontsoleil.github.io/XBRL_GL_Next/tavi-inst.html)
- [HMD View Viewer](https://pontsoleil.github.io/XBRL_GL_Next/tavi-inst-hmd-view.html)

これらは表示用デモであり、正式なTavi検証ツールではありません。taxonomyの意味解釈、factの選択、Propertiesとの連動は行いません。

**現行のHMD→Tavi taxonomy生成器**については、[`tavi-poc/tools/hmd_to_tavi.py`](../../tavi-poc/tools/hmd_to_tavi.py)と[4モデル再現ガイド](../../tavi-poc/README_REPRODUCE_4_MODELS.md)を参照してください。この生成器はHTML ViewerやTaviインスタンスを生成しません。
