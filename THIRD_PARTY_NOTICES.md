# Third-party material and licensing review

This project combines project-authored work with historical and external material of different provenance. Technical validity does not establish copyright, redistribution permission, endorsement, or publication authority. This notice records provenance and publication controls; it is not legal advice.

## Project licence boundary

- MIT applies only to project-authored scripts that carry an MIT notice or whose authorship and MIT treatment are explicitly confirmed.
- CC BY 4.0 applies only to identified project-authored documentation and artifacts.
- Neither licence changes the terms applicable to external originals, standards, taxonomies, code lists, consumer data, or derivative works.
- Repository location, technical modification, or inclusion in a generated artifact does not convert third-party content into project-authored content.

The retained Python tools are project-authored formal tools. Their notices and exact SHA-256 values are recorded in `TaxonomyFramework/INVENTORY.md`.

## XBRL Global Ledger 2015 and 2017

The XBRL GL 2015 Recommendation and XBRL GL 2017 Public Working Draft are external XBRL International materials. Their official packages are not copied into this repository.

- 2015 official package: <https://www.xbrl.org/int/gl/2015-03-25/XBRL-GL-REC-2015-03-25.zip>
- 2015 licence statement: <https://www.xbrl.org/int/gl/2015-03-25/gl-framework-REC-2015-03-25.html#copyright>
- 2017 official package: <https://www.xbrl.org/int/gl/2016-12-01/XBRL-GL-PWD-2016-12-01.zip>
- 2017 licence statement: <https://www.xbrl.org/int/gl/2016-12-01/gl-framework-2017-PWD-2016-12-01.html#copyright>

The linked terms must be reviewed for each intended use. Reuse should import official entry points where appropriate or use project-owned namespaces for independently governed concepts.
