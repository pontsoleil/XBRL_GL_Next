# Third-party material and licensing review

This project combines project-authored work with historical and external
material of different provenance. Technical validity does not establish
copyright, redistribution permission, endorsement, or publication authority.

## Project licence boundary

The repository licence is interpreted as follows:

- MIT applies only to project-authored scripts that carry an MIT notice or
  whose authorship and MIT treatment are explicitly confirmed.
- CC BY 4.0 applies only to identified project-authored documentation and
  artifacts.
- Neither licence changes the terms applicable to external originals,
  standards, taxonomies, code lists, consumer data, or derivative works.
- A file with unresolved ownership, licence, confidentiality, privacy, or
  redistribution conditions is not registered even in the Private repository.

Repository location, technical modification, or inclusion in a generated
artifact does not convert third-party content into project-authored content.

## UN/CEFACT material

WORK analysis material includes content derived from UN/CEFACT CCL D25A,
UNTDED, UNTDID, or code lists. The corresponding `source/unece/` and taxonomy
experiment structures are not currently registered in the target Private
repository. General availability for use is not treated as unrestricted
redistribution or derivative-work permission.

- UN/CEFACT standards: <https://unece.org/trade/uncefact/standards>
- UN/CEFACT call to action:
  <https://unece.org/trade/uncefact/CallToAction-Digitalization>
- United Nations terms of use:
  <https://www.un.org/en/about-us/terms-of-use>

No written redistribution permission is recorded for the copied D25A analysis
data. It remains outside the Private repository. Future use requires an
official download recipe, a source-specific permissive licence, or written
permission. Preserve UN unique IDs and release provenance in mappings.

## Python tools

Historical scripts exist in the target repository, and newer candidates exist
in WORK. Only a script with an explicit MIT notice or separately confirmed
project authorship is eligible for MIT treatment. Preserve its notice and
record the exact source SHA-256. A script without confirmed authorship and
licence is not eligible for Private registration.

## Project documents and review evidence

The revised Framework DOCX files and `docs/ChatGPT` review evidence exist in
WORK but are not registered by this candidate. Possession and repository
ownership do not prove publication authority. They require an explicit
project-authorship and sharing decision before any Private registration.

## Release rule

Before any copy, classify the file as project-authored, external original,
derivative, generated output, consumer data, or review evidence. Record source,
version, SHA-256, applicable terms, data sensitivity, and approved sharing
scope. Generated Phase 0 manifests are planned evidence and are not registered
by this candidate.

Do not register a held file merely to repair a README link. This notice is a
provenance and publication control record, not legal advice.
